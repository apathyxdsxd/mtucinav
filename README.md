# МТУСИ Навигатор (MtuciNAV)

Веб-приложение для навигации внутри здания МТУСИ (Московский технический университет связи и информатики). Позволяет находить аудитории с помощью NLP-поиска, строить маршруты между этажами и определять местоположение по QR-кодам.

## Стек технологий

| Слой | Технологии |
|------|-----------|
| Frontend | React 19, TypeScript, Vite 8, React Router v7 |
| Backend | Python, FastAPI, Uvicorn |
| ML/NLP | scikit-learn (TF-IDF + Cosine Similarity), pandas |
| Стилизация | CSS (glassmorphism, анимации, CSS-переменные) |
| Деплой | Vercel |

## Возможности

- **NLP-поиск аудиторий** — поиск по естественному языку (TF-IDF + косинусное сходство). Можно искать по номеру, названию, преподавателю или предмету
- **Построение маршрутов** — алгоритм Дейкстры по взвешенному графу здания (5 этажей, 85 узлов)
- **QR-навигация** — определение текущего местоположения по QR-коду
- **Интерактивные SVG-карты** — визуализация этажей с анимированным отображением маршрута
- **Генерация QR-кодов** — 65 QR-кодов для печати с фильтрацией по этажам

## Запуск

### Frontend

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

### Backend

```bash
pip install -r backend/requirements.txt
python backend/main.py
```

API будет доступно на `http://localhost:8000`

### Тестирование NLP-модели

```bash
python backend/train.py
```

## Как это работает

### NLP-поиск

1. Каждая аудитория описана набором ключевых слов в `rooms_data.json`
2. При запуске сервера данные векторизуются через TF-IDF (униграммы + биграммы)
3. Поисковый запрос пользователя преобразуется в TF-IDF вектор
4. Вычисляется косинусное сходство с каждой аудиторией
5. Возвращаются top-K результатов с уровнем уверенности (high/medium/low)

### Навигация

1. Пользователь сканирует QR-код → определяется текущая позиция
2. Через NLP-поиск или клик по карте выбирается аудитория назначения
3. Алгоритм Дейкстры строит кратчайший маршрут по графу здания
4. Маршрут отображается анимированной линией на SVG-карте

### Граф здания

- 5 этажей по 17 узлов: 10 комнат + 5 коридорных узлов + 2 лестницы
- Рёбра с весами: комната-коридор (2), коридор-коридор (2), лестница (3)
- Межэтажные связи через лестничные узлы
